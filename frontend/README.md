# AI 安全知识情报系统 · 前端

Vue 3、TypeScript、Vite、Pinia、Element Plus、Axios 和 ECharts 前端。当前版本使用小组后端接口，真实资料与显式虚构样本分开查询；网络失败不会替换成模拟成功数据。

## 启动

Node.js 要求：^22.18.0 或 >=24.12.0。在本仓库 frontend 目录执行：

```powershell
npm.cmd ci
npm.cmd run test:unit
npm.cmd run type-check
npm.cmd run build
npm.cmd run dev
```

打开 http://127.0.0.1:5173/。start-dev.cmd 可启动已安装依赖的开发服务。该命令只启动前端，后端、数据库和 Agent 按各自模块说明运行。

沿用 VITE_API_BASE_URL，默认示例为 /api/v1；可将 .env.example 复制为 .env.local。Vite 将 /api 代理到 http://127.0.0.1:8010，需要调整时：

```powershell
$env:ICT_BACKEND_ORIGIN = 'http://127.0.0.1:8010'
npm.cmd run dev
```

问答需要后端签发的普通短期用户令牌。用户可在 `/login` 使用手机号账号登录，或通过访问令牌入口验证已有普通用户令牌；手机号注册与登录需要后端 0012 迁移及相应接口。开发可设置 ICT_LOCAL_SESSION_FILE 指向本机会话 JSON（access_token、expires_at、is_demo）。会话文件不提交仓库。/__local/session 仅在本地开发启用并校验 Host、Origin；禁止把管理员、Agent 服务或模型密钥放入 VITE_ 变量。

普通 Axios 请求默认超时为 120 秒，为后端网关和 Agent 有界工作流预留返回时间。当前没有单独的超时环境变量，沿用现有调用方式，仅调整统一默认值；上游服务和反向代理的超时需在部署时配套设置。该值属于等待上限，不代表响应速度或长期 SLA。

## 页面

可追溯问答使用带尖角的大话语框，框内助手回答靠左、用户消息靠右；框外显示黑白小猫形象。输入区只保留问题输入框和发送按钮。新建会话保留已由后端保存的对话；可选择旧会话继续追问。历史使用普通用户身份读取 `/agent/sessions` 与 `/agent/sessions/{id}`，真实资料和虚构样本分开显示。选择及回答模式等展示信息缓存在当前浏览器，正文仍由后端保存。历史加载失败显示错误并支持刷新。小猫是页面形象，等待回答时有轻微动画。

历史验证（2026-10-12）：当时合并版本通过 20 项单元测试、类型检查与生产构建。浏览器使用隔离的合成接口数据验证了新建会话保留历史、切回旧会话、刷新恢复、引用展示、模型认证失败不清除用户授权、用户授权过期后草稿保留与重试，以及桌面/手机布局和搜索框焦点。该轮未启动实际后端，以上不等于真实 RAG 或生成模型联调通过。历史能否长期保存取决于后端账户和数据库；更换后端或用户账户会看到相应账户的记录。

建议演示：首页展开指标 → 情报详情查看证据 → 情报分类切换来源与富化 → 问答追问 → 点击引用核对原文。

基础对话与安全资料回答分别展示；模型一般解释标记为未经实时来源核验。证据覆盖、工具记录及服务错误仅按实际返回内容显示。失败问题可重新放回输入框或重试，授权跳转保留草稿。

### 登录页面

登录页采用白底、黑色文字及主按钮、圆角输入框和文字式密码显隐。顶部“登录”及问答未授权提示均可进入，支持返回工作台和浏览公开情报。

当前手机号账号入口通过 POST `/auth/register` 或 `/auth/login` 向后端提交手机号和密码，验证后端返回的短期令牌及用户身份，再返回问答页面。密码和用户令牌不持久化到浏览器存储；凭据仅在当前运行内存中使用。退出会请求后端撤销当前令牌。手机号注册与登录的要求及限制见文末；当前未实现密码找回、短信验证或第三方登录。

“访问令牌”调用现有后端验证普通用户身份，优先 GET `/auth/me`；旧后端返回404时使用受保护的 GET `/agent/sessions?page=1&page_size=1` 验证。只有验证通过才将令牌放入当前运行内存并返回问答，返回路径限制为本站路径。开发模式可读取已有有效本地授权并验证；生产模式隐藏本地授权入口。

登录页分为 LoginView 布局、LoginForm 表单、useLogin 状态和 api/auth 验证模块。账号接口使用后端约定的手机号与密码字段，令牌有效期由后端响应提供。

历史设计与验证（2026-10-13）：当时“账号密码”仅为界面预览，未向服务端发送密码，尚无注册入口。该轮类型检查与构建、桌面/手机布局、密码显隐、普通本地用户授权、无效令牌拒绝及返回路径限制通过；连接失败提示使用独立浏览器临时响应验证，未验证账号密码登录。该记录保留当时范围；当前版本已合入手机号注册与登录代码，不沿用这轮历史记录作为新接口联调结果。

## 当前验证与限制

历史验证（2026-10-09）：45 条真实 OSV 来源记录已索引；两轮问答成功，返回 2 个来源、4 段可逐字核对的证据，会话保存 4 条消息。当时使用 E5 实时检索和 extractive 资料摘录模式，远程 LLM 调用为零，不能当作生成式模型已验证。测试数据库不随前端上传，其他成员的记录数量可能不同。

以下是2026-10-09的历史限制（最新结果见文末）：七类来源表示分类覆盖，不表示每类均有采集数据。当时本地论文、POC 和公开利用状态没有实际富化记录；不能把接口支持写成已完成自动富化。生产登录、所有来源采集、自动论文关联、公开利用状态富化、远程生成模型和部署性能仍需联调。

## 接口联调

继续使用后端现有 /api/v1 接口，具体参数以各模块 OpenAPI 为准：

- /sources：source_id、名称、category、enabled；确认七类来源值和离线样本标记。
- /documents：is_demo、page、page_size 等查询参数；确认筛选、总数、document_id、source_id、external_id、CVE、发布日期和风险字段。
- /documents/{id}：正文、原文 URL、版本 content_hash 与 revisions；引用必须能定位保存版本。
- /documents/{id}/enrichment：document_id、content_hash、source、external；八类字段的 state/value/evidence_id，以及 extraction_method、review_state、证据 locator/excerpt。
- /agent/query：query、session_id、is_demo；回答、sources、evidence、response_kind、retrieval_mode、status、coverage、question_type、requirement_coverage、retrieval_summary、limitations、tool_trace 和错误分类；缺失工作流字段时兼容旧响应。
- /auth/me：验证短期用户令牌；旧后端不提供该接口时，用受保护的会话列表接口验证。
- /auth/register、/auth/login：提交 phone、password，返回短期用户令牌、有效期等身份信息；需后端 0012 迁移。
- /auth/logout：撤销当前普通用户令牌。
- /agent/sessions：page、page_size；会话列表、total、is_demo、provider、turn_count、updated_at。
- /agent/sessions/{id}：历史消息和引用；普通用户令牌签发、过期与生产登录方式需统一。

富化响应结构示意（字段缺失明确标记，不补造值）：

```json
{"document_id":"示例文档ID","content_hash":"对应版本哈希","source":{"cwe":{"state":"unknown","value":null}},"external":{}}
```

## 构建与部署

构建输出 dist。生产服务需要 SPA 路由回退及 /api 到真实后端的反向代理；不能依赖 Vite 本地会话桥接。前端目录不附带虚构后端服务。ECharts 相关首页 chunk 仍有体积警告，后续可优化拆包。

不提交 node_modules、dist、本地 .env、会话文件、密钥、测试截图和个人编辑器配置。

## 手机号注册和登录

`/login?mode=register`可注册手机号账号，普通登录页选择手机号登录。需后端0012迁移及`/auth/register`、`/auth/login`、`/auth/me`、`/auth/logout`。密码15—128字符，注册含确认密码；手机号目前仅作为账号，未短信验证。登录凭据只存内存，手动账号刷新后需重新登录，不自动换成开发机旧用户。原访问令牌入口保留，退出会撤销当前服务端令牌。
