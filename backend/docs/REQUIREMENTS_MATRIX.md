# 赛题要求与当前差距

本轮依据正式赛题 PDF、任务简报及后端/Agent_RAG 协作清单。完整后端要求/责任/实现/验收矩阵见 [BACKEND_UPGRADE_STATUS](BACKEND_UPGRADE_STATUS.md)；评分口径见 [EVALUATION](EVALUATION.md)。正式 PDF 决定验收；MVP 建议用于开发顺序，未阻止用户本轮要求的高档覆盖。AI 风险类别仅辅助，不单独算分。

| 赛题后端方向 | 实际状态 | 剩余验收 |
|---|---|---|
| 至少七类真实来源、更多数据类型 | 十二个实际适配器，七类均采集成功，有规则相关项；增加 paper/standard/policy/regulation，保留内容完整性和来源性质 | 相关性独立审核；全量/实时覆盖尚有限制，不能把 URL 数或泛安全摘要算七类 |
| 五种以上富化 | 真实 affected/CWE/CVSS/修复/分析证据；另有 NVD POC 元数据，至少五维，不拆版本凑数 | 标注准确性/recall、Agent 自动语义关联与审核；链接元数据不当复现或分析完成 |
| 清洗/关联/更新/查询 | 版本/原文/证据/别名、保守关联、幂等、异步任务/outbox/游标、逻辑失效/事件重放、列表/统计/关系/Tool | 来源发现边界与持续遗漏清单 |
| 语义理解、多轮问答 | 保留内置 PostgreSQL 数组索引与 DeepSeek 多轮，真实两轮已保存；网关/外部索引证明/用户归属接口和测试完成 | 独立 Embedding Key 或队友真实 RAG 服务；尚无真实语义向量 |
| Agent 工作流/跨文档推理 | 后端 V1 Tool、query、索引/证据协议就绪，超时/错误/引用/轨迹可审查 | 队友实现并部署 Agent/RAG，真实联调与效果评测；后端不重复写竞争模块 |
| 工程化与演示 | 增量迁移、Docker/Redis/worker/唯一 beat、虚构演示隔离，52 项测试、23 项实际环境/离线检查、重启保留 | 真实外部服务端到端；测试替身不计真实 RAG 成果 |
| 延迟/准确率/召回率 | 真实 HTTP 小样本计时、可观测发布延迟、版本固定审核集与严格计分脚本 | 独立审核与观察期；当前没有≥95%或≤6h达标成绩 |

前端展示、Agent 模型优化、多 Agent/可解释推理链与整体比赛材料由团队协作完成。已有后端能力不能等同整体赛题系统验收。保留旧数据/密钥/迁移，未处理 GitHub。实际结果见 [VERIFICATION](VERIFICATION.md)。
